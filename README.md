# The Health Watchers Website

A modern React website for The Health Watchers, focused on population health in-home medical care, telemedicine support, senior living medical support, care gap closure, and program visibility.

## Tech Stack

- Vite
- React
- Tailwind CSS
- Lucide React icons

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deploying to Vercel

1. Import this GitHub repository into Vercel.
2. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
3. Add the custom domains:
   - `thehealthwatchers.com`
   - `www.thehealthwatchers.com`
4. Update DNS in GoDaddy using the records Vercel provides.

## SEO Landing Pages

In addition to the single-page React site, the project generates fully static,
crawlable landing pages under `public/` for stronger organic and local SEO:

- **Service pages** (`/services/<service>/`) — an in-depth explanation of each
  service, plus a `/services/` hub.
- **GEO-targeted service-area pages** (`/service-areas/<city>/`) — location pages
  for communities across Metro Detroit (Detroit, Troy, Royal Oak, Southfield,
  Dearborn, Warren, Sterling Heights, Farmington Hills, Novi, West Bloomfield),
  plus a `/service-areas/` hub.
- `sitemap.xml` and `robots.txt`.

Each page is server-rendered HTML (no JS required to read content) with unique
title/description/keywords, canonical URL, Open Graph/Twitter tags, and JSON-LD
structured data (`Service`, `MedicalBusiness`/`LocalBusiness` with geo
coordinates, `BreadcrumbList`, and `FAQPage`). The homepage links into these
pages for internal-link equity.

These files are generated by `scripts/generate-seo-pages.mjs`:

```bash
npm run seo
```

To add or edit pages, update the `services` and `locations` data arrays in that
script and re-run it. `npm run build` runs the generator automatically via the
`prebuild` step, so deploys always ship fresh pages.

## Notes

- The contact form is currently front-end only. It needs to be connected to a form backend, CRM, email service, or serverless function before launch.
- The site includes SEO metadata and JSON-LD schema for MedicalOrganization, Service, and FAQPage.
- This website should not be used to submit protected health information.
